# Crypto Crash Alert — النظام الهجين (هاتف رئيسي + بوت Telegram)

تطوير أبو عبدالله الشامي

## الفكرة

```
 ┌───────────── الهاتف الرئيسي (Android) ─────────────┐
 │  Foreground Service (يعمل والشاشة مغلقة)           │
 │   ├─ مراقبة الأسعار: Binance + Bybit + OKX          │
 │   ├─ كشف الهبوط: ≥ 5% خلال 60 ثانية                │
 │   ├─ بوت Telegram (مستهلك getUpdates الوحيد)        │
 │   └─ SQLite: المشتركون، التنبيهات، الإعدادات         │
 └───────────────┬────────────────────────────────────┘
                 │  sendMessage لكل مشترك
                 ▼
     مستخدمو Telegram (بدون تطبيق، بدون Token)
     /start  /stop  /status
```

- التطبيق يُثبَّت على **هاتف واحد فقط**.
- أي شخص يفتح Telegram ويبحث عن البوت ويضغط **/start** فيُسجَّل `chat_id` الخاص به تلقائياً في قاعدة بيانات الهاتف الرئيسي.
- عند هبوط أي عملة مراقَبة بنسبة 5% أو أكثر خلال 60 ثانية، يرسل الهاتف الرئيسي التنبيه إلى **جميع** المشتركين.

## أوامر البوت

| الأمر | الوظيفة |
|---|---|
| `/start` | الاشتراك في التنبيهات |
| `/stop` | إلغاء الاشتراك |
| `/status` | حالة الخدمة (المراقبة، المصادر، عدد المشتركين، حالة اشتراكك) |

## ⚠️ متطلبات التشغيل — بصراحة

- الهاتف الرئيسي **يجب أن يبقى قيد التشغيل**.
- التطبيق وخدمة المراقبة **يجب أن يبقيا فعّالين**.
- **الإنترنت يجب أن يكون متاحاً** باستمرار.
- **إذا توقف الهاتف الرئيسي** (إطفاء، نفاد بطارية، انقطاع إنترنت، إيقاف الخدمة) **تتوقف مراقبة الأسعار وإرسال التنبيهات فوراً**، ولا يرد البوت على أي أمر.
- لا يوجد خادم احتياطي ولا قاعدة بيانات سحابية؛ النظام لا يعمل إذا كان الهاتف الرئيسي مغلقاً.
- البوت يخبر كل مشترك بذلك عند `/start`، والوصف المختصر للبوت يقول: إن لم يرد على `/status` فالخدمة متوقفة.
- رسائل Telegram التي تُرسل أثناء توقف الهاتف تنتظر لدى Telegram حتى 24 ساعة، وتُعالَج عند عودة الهاتف (لذلك `/start` لا يضيع، لكن التنبيهات خلال فترة التوقف لا تُعوَّض).

نصائح للاستقرار: أبقِ الهاتف على الشاحن، اضغط «استثناء التطبيق من تحسين البطارية»، اسمح بالإشعارات، وفي هواتف Xiaomi/Huawei/Oppo فعّل «التشغيل التلقائي» للتطبيق من إعدادات الهاتف.

## الإعداد خطوة بخطوة

1. في Telegram افتح **@BotFather** ← `/newbot` ← انسخ الـ Token.
2. ثبّت التطبيق على الهاتف الرئيسي وافتحه.
3. الصق الـ Token في خانة **Bot Token** ← **حفظ** ← **اختبار الاتصال** (يظهر اسم البوت).
4. فعّل **تشغيل البوت** و**تشغيل مراقبة العملات**.
5. أرسل رابط البوت (`t.me/اسم_البوت`) لمن تريد؛ كل شخص يضغط `/start`.
6. جرّب زر **إرسال رسالة تجريبية لكل المشتركين**.

## الإعدادات (محفوظة في SQLite)

| الإعداد | الافتراضي |
|---|---|
| نسبة الهبوط | 5% |
| النافذة الزمنية | 60 ثانية |
| فترة التهدئة لكل عملة | 15 دقيقة (حتى لا يتكرر نفس التنبيه من 3 منصات) |
| معدل التحديث | كل 5 ثوانٍ لكل منصة |
| العملات | 20 عملة رئيسية، أو `ALL` لكل أزواج USDT |
| المنصات | Binance, Bybit, OKX (Binance يتحول تلقائياً إلى data-api.binance.vision إن حُجب) |

طريقة الحساب: أعلى سعر خلال آخر 60 ثانية مقارنةً بالسعر الحالي، لكل منصة على حدة.

## قاعدة البيانات (SQLite محلية)

- `subscribers`: `chat_id`، الاسم، نوع المحادثة، أول ظهور، **تاريخ الاشتراك**، **حالة الاشتراك** (`active` / `stopped` / `blocked`).
- `alerts`: آخر 1000 تنبيه (العملة، المنصة، النسبة، السعران، عدد من أُرسل لهم ومن فشل).
- `settings`: إعدادات المراقبة، حالة المفاتيح، آخر `offset` لـ getUpdates.

من يحظر البوت يُعلَّم تلقائياً `blocked` ولا يُرسل إليه.

## مستهلك واحد فقط لـ getUpdates

- خيط واحد فقط للاستقبال، مع حارس على مستوى التطبيق يمنع وجود نسختين.
- `deleteWebhook` عند التشغيل (لا يعمل getUpdates مع Webhook).
- «اختبار الاتصال» يستخدم `getMe` فقط ولا ينافس البوت.
- إذا شغّلت نفس الـ Token على جهاز أو خادم آخر يردّ Telegram بخطأ 409، ويظهر في التطبيق تحذير واضح بدل التجاهل.

## الأمان

- **لا يوجد Token في الكود ولا في GitHub.** يُدخل من التطبيق فقط.
- يُشفَّر بـ AES-256-GCM بمفتاح داخل **Android Keystore**، ويُحفظ النص المشفّر فقط.
- النسخ الاحتياطي معطّل (`allowBackup=false`) فلا يغادر الـ Token الهاتف.
- لا يُطبع في السجلات: كل رسالة خطأ تمر عبر `Redact`، ولا يوجد HTTP logging.
- بعد الحفظ لا يُعرض الـ Token مرة أخرى في الواجهة.

## البناء

لا تحتاج Android Studio: ارفع المشروع إلى GitHub وسيبني **GitHub Actions** ملف APK تلقائياً
(تبويب Actions ← آخر تشغيل ← Artifacts ← `CryptoCrashAlert-apk`).

محلياً: `./gradlew assembleRelease` (يتطلب Android SDK و JDK 17).

## هيكل الكود

```
app/src/main/java/com/alshami/crashalert/
├─ App.kt                    قنوات الإشعارات + إشعار الهبوط المحلي
├─ data/Db.kt                SQLite (المشتركون، التنبيهات، الإعدادات)
├─ data/Config.kt            إعدادات المراقبة
├─ security/TokenStore.kt    تخزين الـ Token مشفّراً (Keystore)
├─ monitor/PriceSources.kt   Binance / Bybit / OKX
├─ monitor/CrashDetector.kt  كشف الهبوط بنافذة متحركة + تهدئة
├─ monitor/PriceMonitor.kt   الاستطلاع المتوازي
├─ telegram/TelegramApi.kt   عميل Bot API
├─ telegram/TelegramBot.kt   getUpdates (مستهلك واحد) + البث
├─ telegram/Messages.kt      نصوص الرسائل
├─ service/MonitorService.kt Foreground Service (specialUse) + WakeLock
├─ service/BootReceiver.kt   إعادة التشغيل بعد إقلاع الهاتف
└─ ui/MainActivity.kt        واجهة الهاتف الرئيسي
```

> التنبيهات للمعلومة فقط وليست نصيحة استثمارية.
